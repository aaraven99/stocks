# Roadmap

## Before evaluating performance claims

1. Obtain a licensed, point-in-time US-equity universe and delisting-aware historical data export,
   then pass the existing coverage audit before running the implemented cross-sectional engine.
2. Add dated SEC, earnings, news, and fundamentals adapters with source-specific freshness tests.
3. Run multi-universe and multi-regime walk-forward research with costs, slippage, bootstrap, and
   parameter-sensitivity artifacts.

## After the evidence gates above

4. Add portfolio-level sector/correlation constraints and position-sizing simulation.
5. Add a provider-backed paper broker adapter with reconciled fills, never live execution by default.
6. Add dashboards only after the underlying forward ledger and data provenance are stable.
