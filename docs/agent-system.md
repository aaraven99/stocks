# Agent system

| Agent | Output | Guardrail |
| --- | --- | --- |
| Technical | trend/momentum evidence | values originate in features |
| Regime | market state | inputs cite market observations |
| Risk | liquidity, volatility, concentration checks | can downgrade only |
| Bull/Bear | structured pro/con evidence | cannot create figures |
| Final decision | classification plus references | cannot override quantitative score by default |
| Optional OpenRouter narrative | explanation of provided evidence | not included in score or execution |
